# Student Registration System

A React-based student registration system for managing course types, courses, course offerings, and student registrations.

## Features

- Add, edit, and delete course types
- Add, edit, and delete courses
- Create course offerings by combining course types and courses
- Prevent duplicate course offerings
- Register students for available course offerings
- Filter registered students by course offering
- Responsive interface for managing registration data

## Tech Stack

- React.js
- JavaScript
- HTML
- CSS
